# study_development

개발 학습 기록 저장소. 주제별로 폴더를 나눠 하나씩 정리한다.

## 주제

| 주제 | 폴더 | 상태 |
|------|------|------|
| Kubernetes | [`kubernetes/`](./kubernetes) | 🏃 진행 중 |
| Proxy | [`proxy/`](./proxy) | 🏃 진행 중 |

## 정리 규칙

> **핵심 규칙: 대화하며 나온 개념만 정리한다.**
> "프록시 정리해줘" 같은 식으로 미리 개념을 생성해 채우지 않는다.
> 실제로 소통하며 다룬 내용에 대해서만 문서를 작성/갱신한다.

- 주제마다 폴더 하나.
- 개념 정리는 마크다운, 실습 코드/설정은 같은 폴더에 함께 둔다.
- 커밋은 "무엇을 배웠는지" 단위로 작게 쪼갠다.
